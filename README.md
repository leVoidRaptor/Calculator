# Mathex Calculator

A beginner-friendly command-line calculator built with Python.

Mathex Calculator performs seven arithmetic operations on two user-provided numbers. It includes input validation, error handling, and a continuous execution loop.

## Features

- Accepts two numerical inputs.
- Supports seven arithmetic operations.
- Validates numerical inputs.
- Prevents division by zero.
- Handles invalid operator selections.
- Supports continuous calculations.
- Handles common runtime errors.

## Supported Operations

| Operator | Operation | Description |
|:---:|---|---|
| `+` | Addition | Adds two numbers. |
| `-` | Subtraction | Subtracts the second number from the first. |
| `*` | Multiplication | Multiplies two numbers. |
| `/` | Division | Divides the first number by the second. |
| `//` | Floor Division | Returns the floor of the division result. |
| `%` | Modulus | Returns the remainder of the division. |
| `**` | Exponentiation | Raises the first number to the power of the second. |

## How to Use

1. Enter `C` to start calculating.
2. Enter the first number.
3. Enter the second number.
4. Select an arithmetic operator.
5. View the result.
6. Enter `C` to perform another calculation or `E` to exit.
